# 主应用背景

## 作用范围

背景设置位于「系统设定 → 外观设置 → 应用背景」。主窗口的标签栏、导航、聊天、工作区、据点、设置页和新标签页共用一张底图。滚动消息、切换页面、收起导航不会重新裁切图片。

浏览器、NapCat、Arca 等独立 `WebContentsView` 的网页内容不参与透景。桌宠窗口也不使用这张背景。

## 绘制与材质

- `MainView.vue` 只挂载一个 `AppWallpaper.vue`，位于窗口内容底层且不接收鼠标事件。
- 图片加载成功后才给根节点添加 `data-app-background="active"`；读取失败时保留默认页面材质。
- 未启用底图时，`app-background.css` 为各主页面及据点、工作区等内部主内容面提供统一的淡渐变与斜纹，复用明暗主题令牌，不覆盖阅读卡片或代码内容底色。
- 启用底图后自动切换为透景材质，并停用默认渐变；不改变主题基色、字体、像素边框和品牌状态色。
- 导航和标题使用侧栏材质；卡片使用面板材质；消息、输入、文档阅读、文本编辑和终端使用至少 90% 不透明度的阅读材质。媒体查看器保留自身底色。
- 工作区主体共用一层面板与模糊，资源树、协作容器和内部标题不再重复铺底。阅读层根据主体已有的不透明度补足到目标值，避免连续叠加后变成黑块；中央空态也获得相同的底色承托。
- 启用自定义背景时隐藏导航的横向纹理，保留按钮和头像本身的像素边框与层次。
- 工作区终端开启 xterm 透明绘制，监听主题与主窗口背景状态的变化；默认画布透景，显式 ANSI 背景色仍按终端协议显示。切换背景不重建终端、不丢失输出。系统日志与社交终端也使用透景底色，并关闭扫描线装饰。
- 毛玻璃用于稳定的侧栏和标题区域，不为长消息列表逐项增加模糊层。
- 明暗主题的遮罩均来自 `--ui-bg-canvas`，不再各维护一份白色或黑色遮罩。

### 浅色材质

`light-theme.css` 落实已确认的浅色设计稿，只匹配文档根节点的浅色主题；深色样式、组件布局、品牌色、像素边框及阴影形状继续沿用现有实现。

- 未启用图片时，仅微调浅色中性边框与辅助文字对比度，保留默认渐变底板。
- 均衡背景参数下，侧栏与普通面板为 86% 不透明度，普通阅读层为 94%；三大聊天页侧栏为 82%、标题为 78%，消息和输入为 96%。据点旁白保留独立材质，不转换为普通角色气泡。
- 上述透明度由已保存的背景参数连续映射，通透、均衡、专注以及手动细调仍然生效；面板参数为 100% 时对应面板和阅读层仍为实色。旧参数不覆盖、不迁移。
- 浅色自定义背景至少作 2px 柔化；用户设置更大的模糊值时继续使用用户值，亮度、饱和度、对比度、位置和填充方式保持有效。背景设置中的缩略窗口使用相同材质规则。
- 标签栏保留白色稳定底色。工作区使用一层主体底板和轻量协作栏覆盖，消息及输入继续采用一致的阅读材质，不对每条消息增加毛玻璃。

## 设置与兼容

`useAppBackground.ts` 共用设置、加载请求、预设和 CSS 参数。设置页缩略窗口使用同一个图片组件和材质参数。

提供通透、均衡、专注三档预设；细调支持可见度、模糊、亮度、饱和度、对比度、主题遮罩、面板不透明度、毛玻璃、填充方式和水平／垂直位置。切换预设保留图片与位置；点击「保存设置」持久化参数。上传和删除立即保存。

存储继续使用 `ui.chatBackground.settings`、`ui.chatBackground.mime` 和 `/api/system/chat-background`，已有图片与自定义参数无需迁移或重新上传。首次使用默认采用均衡参数；已有自定义参数不会被覆盖，可手动选择预设重新调整。Web 端图片请求复用资源查询参数鉴权。

图片支持 PNG、JPEG、WebP，最大 15MB。后台继续校验实际图片格式。设置加载合并并发请求，打开设置页不会覆盖尚未保存的预览调整；持久化和样式投影会限制数值范围。

## 维护入口

背景配置与文件由 `packages/backend/src/services/system/chatBackgroundService.ts` 管理；前端 `composables/ui/useAppBackground.ts` 处理应用生命周期，`assets/app-background.css` 提供统一材质变量。新增页面应消费这些变量，而不是另建透明度或毛玻璃配置。

排查背景切换不同步时核对服务端配置、前端对象 URL 与页面激活状态；切换和卸载须回收旧资源。深浅主题与可读性要求见 [S06](./S06_UI_UX_DESIGN_SPEC.md)。
