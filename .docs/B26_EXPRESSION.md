# 表达调教与说话手册

表达调教提供用户批注、每角色说话手册、后台学习、表达规则编辑与本轮素材。前端入口为「提示词 → 表达调教」，消息上的标注操作复用同一套数据服务。

## 数据与作用域

| 数据 | 权威位置 | 范围 |
| --- | --- | --- |
| 表达规则正文 | 提示词工作区的 `components/expression/thinking` | 所引用的框架 |
| 用户批注 | `expression_marks` | 角色、来源会话、正式消息及原文修订 |
| 说话手册及版本 | `expression_handbooks`、`expression_handbook_versions` | 角色共享 |
| 学习配置 | `expression_settings` | 角色学习开关和全局素材选项 |
| 学习任务及批次 | `expression_learning`、`expression_learning_batches` | 来源修订 |
| 编译版本 | `expression_turn_versions`、`expression_replies` | 逻辑执行与正式消息 |
| 素材冷却 | `expression_state` | 角色、会话与主线代次 |

自动学习从主线用户消息中识别明确的语气纠正。侧会话支持用户主动标注，标注形成显式学习来源。重复表达提示读取当前桌面会话的有效正式发言，据点场景使用自身的上下文边界。

提示词工作区按资源完整性补入「我的预设」。所引用的组件齐备后才加入该框架，自定义资源包按自身提供的组件完成发布校验。

## 批注组织与来源

原始批注和「对味原话」只在来源 Thread 内选材。角色共享说话手册，主线与侧线分别通过自身框架引用手册正文。模型配置切换继续使用同一角色的数据。

批注保存 `source_revision`。选材与后台学习核对消息归属、有效状态和修订。原文编辑或撤回后，管理页保留批注并显示暂停状态。用户重新保存时核对引用仍属于当前正文，再确认当前修订。迁移 `0033_expression_source_revision` 将旧批注视为来源初始修订，较新原文需重新确认。

同一角色、会话、消息和规范化选区的新增请求更新既有批注，省略批注正文时沿用已有正文。重复请求使用同一 ID，写入在 SQLite 即时事务中完成。旧库的重复记录保留供管理，选材按消息和规范化选区去重。

## 学习与恢复

学习任务以来源指纹和修订号去重，模型结果提交前再次核对来源。批次固定成员，后续批注进入下一批。进程中断后从持久批次恢复，模型失败按有界次数与延迟重试。

模型入口为 `model.task.expression_learning`，未指派时遵循任务模型到主模型和环境配置的回退规则。模板为 `tasks/expression_learning`。输出经结构校验、置信度门槛、规则上限与来源校验后更新手册。

说话手册按角色保存，学习与素材各自受配置控制。用户可以手动编辑规则、查看学习状态和历史版本、恢复版本或发起重新学习。

## 上下文接入

编译器提供 `speech_handbook`，默认框架通过手册组件渲染。可编辑表达规则与提示词页面共用草稿和发布流程，自定义框架按其组件引用决定发送内容。配置升级补入缺失的内置资源，用户布局和指派保留自身内容。

发言前 SelfMind 引导由独立组件 `components/expression/selfminding` 提供，内置输出约定引用该组件。正文编辑、停用和角色替换统一通过[提示词管理](./B17_PROMPT_WORKSPACE.md#selfmind-引导)维护。

本轮素材从当前可见的记忆检索结果、当前 Thread 的有效批注和活动记录中选择，经过相关度、长度与冷却限制后进入动态上下文。Realm 执行沿用独立场景边界。

批注统一进入本轮 `package_context`，沿用动态填充深度。历史消息正文与缓存身份保持由原文决定。候选读取最近更新的一百条有效批注，优先近期反馈及话题相关项，最多选择三条反馈、三条短原话。已学入手册的批注正文由对应规则承接。反馈按预算截短，原话示例按完整短句选择。默认总预算三百字，计入外层标签，可设置一百至一千字。

同次执行的素材复用同时比较来源指纹，涵盖有效批注、召回内容、手册、设置与本会话回复。编辑或删除批注清理该会话的素材状态，原文修订变化在下一次选择时使旧缓存失效。

主线编译版本使用逻辑 Execution 身份，正式发言按 `execution_id` 取得对应版本。侧会话继续支持原有 pair 来源。主线清空后素材冷却按新代次重新计算。

## 权限与清理

`/api/expression` 要求管理身份，接口提供批注、手册、版本、学习状态、配置与编译预览。Agent 工具权限由既有门禁管理。

记忆删除与重置会清除含正文的派生素材。清空聊天清理历史编译记录、素材和学习队列，角色手册与表达设置保留。恢复出厂在 SQLite 事务中清理表达数据与其他业务表。

删除批注会使其待学习任务失效，并清除该会话的素材缓存。已学出的手册规则保留为独立角色资料，用户在手册中编辑、删除或回退版本。修改批注重新建立学习依据，旧模型结果提交时仍须通过来源指纹校验。

## 源码入口

- `services/expression/` 提供存储、素材、手册、学习和容器接线。
- `services/context/expressionContext.ts` 管理预览、素材与执行版本。
- `services/expression/store.ts` 管理批注身份、来源修订和会话内候选。
- `routers/expression.router.ts` 提供管理 API。
- `components/expression/` 提供编辑、标注、预览和学习状态。
