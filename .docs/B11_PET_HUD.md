# 桌宠操作面与气泡

## 界面结构

- 默认收起操作面，保留角色、小光点和必要的短句气泡。
- 展开后使用角色脚边的一体式操作面，当前内容与底部导航共享连续表面。
- 展开操作面时立即隐藏对话气泡；收起后按当前播报、回复和触碰状态决定是否重新显示。
- 对话、语音、互动、更多接入原有功能；互动中按需切换造型、穿搭与模型实际提供的动作。
- 互动默认进入“换个样子”，穿搭细节直接位于造型列表下方，动作小剧场单独切换。
- 气泡采用独立柔和色阶，名字与小心形融入气泡内部；按正文尺寸定位，到达宽度上限后折行。
- 思考、录音、识别、窗口调节和待处理事项独立显示；空闲时不显示空状态卡。
- 长回复和历史仍在主应用阅读，桌宠保留打开对话与停止播报入口。

## 材质

操作面沿用已确认的带色半透明方案。暗色为蓝灰，浅色为天蓝银灰，通过一格亮边和短侧面表达厚度。

气泡暗色采用相近蓝灰色，浅色采用珍珠灰；粉色只用于名字、心形与低强度局部色晕。正文不降低整体透明度。

专用像素图案由 `PetHudIcon.vue` 绘制，不替换全站线性图标库。

## 动效

| 交互 | 处理 |
| --- | --- |
| 展开操作面 | 180ms 淡入与 6px 归位 |
| 收起操作面 | 120ms 淡出与 6px 下移 |
| 切换内容 | 90ms 退出、140ms 淡入，内容入场偏移 3px |
| 内容高度改变 | 180ms 局部高度过渡，底部定位保持固定 |
| 气泡出现与消失 | 160ms 淡入与 3px 归位、130ms 淡出 |
| 必要状态出现 | 140ms 淡入与 3px 归位 |
| 图案悬停、按压 | 120ms 两级阶梯反馈，移动 1–2px |
| 正在思考 | 三个小像素交替变亮 |

尊重 `prefers-reduced-motion`，关闭过渡和循环提示动画。保留既有光点反馈，不把新的展开动画施加到角色或光点。

## 定位与交互

- 模型边界只在模型加载和窗口调整时更新，动画帧不驱动 HUD 布局。
- 操作面底部锚定角色脚边，内容增长不改变光点位置；小窗口限制内容高度并允许内部滚动。
- 内容切换期间保留旧高度，再测量新内容的布局高度，避免先塌陷再展开。
- UI 使用独立命中区域，透明窗口其余部分继续穿透。
- 光点外层的层叠级别高于操作面，并扩大透明点击范围，避免展开后被面板遮挡。
- 角色名与状态使用独立透光衬底，背景上的两个像素点缓慢微动，文字位置保持固定。
- “更多”页提供浅色、暗色切换，复用现有主题偏好并与主应用窗口同步。
- 按住说话支持指针和键盘；释放、失焦、取消、切换或卸载时只结束本次按压一次。
- 中文输入法选词期间不通过 Enter 发送消息。

交互生命周期由 `packages/frontend/src/views/Pet3DView.vue` 管理，图标入口为 `components/pet/PetHudIcon.vue`。修改按住说话和浮层时须检查失焦、切换角色与卸载的资源释放；HUD 只投影已有状态，审批和提问提交继续由对应服务负责。


## 交互提醒与跳转

- 桌宠只显示待处理摘要与主应用入口；不承载提问表单、批准操作和长回复。
- 普通对话请求按角色与 Thread 跳转；后台任务请求必须保留 taskId，进入任务中心并打开对应详情。
- 提问、批准、任务提醒共用透光像素面；思考、语音、调节大小和短提示沿用同一材质。用图案和小面积点色区分语义，保留光点原样。
- 多题提问是一组持久化请求：最多八题、每题最多四个选项，默认单选；支持多选、自定义及选项补充。完整填写、回看后统一提交。
- 单选自动推进；补充、文本与多选显式完成本题；提交期间锁定编辑，失败保留草稿。草稿按请求与题目版本保存，最多保留三十组、七天，解决请求后清除。
- 组级十分钟兜底沿用既有规则：非必答超时跳过，必答保留待答。迟到回答在原 Thread 继续。
- 提交身份依据服务端请求的 agentId 校验，任务面板处理其他角色时使用临时输入凭据，不切换当前角色。
- 数据库通过 `0008_agent_input_groups` 迁移增加 questions_json、answers_json；旧单题与既有答案回填为一题组，保留旧字段兼容旧调用。

- 任务详情顶部统一呈现问答和批准 Surface，移除重复的旧批准表单；正文区过滤已置顶的交互节点。任务内容刷新保留现有面板，读取失败支持重试。
