# 世界书

入口：主应用「设置 → 提示词 → 世界书」。角色档案名称旁的地球按钮用于绑定角色世界书：单击打开已绑定的主要世界书，右键或旁边的箭头打开绑定窗口；未绑定时单击直接打开绑定窗口。

世界书是独立于提示词草稿的书库，保存后立即生效，不经过「保存草稿 → 发布」。

## 书库与绑定

- 书库集中管理全部世界书，可新建、导入、导出、重命名、复制、删除；名称忽略大小写不可重复。
- 「已启用的世界书（全局有效）」对所有角色生效。
- 角色可绑定一本 **主要世界书** 与若干 **附加世界书**。主要世界书随角色资源包导出；附加世界书只在本机关联，不随角色导出。
- 生成时按「全局 → 主要 → 附加」合并条目，同一本书只计算一次。
- 删除世界书会同时移出全局启用列表与所有角色绑定；删除角色只移除绑定，书库保留。

## 条目

| 字段     | 说明                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------ |
| 触发策略 | 蓝灯常驻；绿灯在扫描范围内出现任一关键词时触发；关闭则不参与。关闭的条目在列表中自动排到末尾，重新开启时恢复原来的蓝绿灯 |
| 关键词   | 不区分大小写的子串匹配，逐条消息判断，不跨消息拼接                                                                       |
| 顺序     | 数值越小在世界书块中越靠前；多本书合并时同顺序保持书的先后                                                               |
| 触发概率 | 满足条件后实际注入的概率，0–100                                                                                          |
| 持续轮数 | 绿灯在关键词最后一次出现后继续保持的对话轮数                                                                             |
| 生效场景 | 桌面、据点群聊、社交私聊、社交群聊；都不勾选表示全部场景                                                                 |
| 标题     | 只用于编辑时辨认，不发送给模型                                                                                           |

条目正文支持 `{{char}}`（角色名字）与 `{{user}}`（用户名字），与酒馆框架宏一致；其余文本原样注入，不执行模板语法。

## 全局激活设置

- 扫描深度：关键词扫描最近多少条消息（含当前输入），默认 2。
- Token 上限：世界书最多占用的 Token，0 表示不限。与酒馆一致，预算按蓝灯优先、其次顺序数大者优先占用；一旦放不下，其余条目全部舍弃。

## 注入位置与提示词缓存

激活的条目按顺序数合并为一段，**只放在末尾的本轮动态上下文中**，不进入系统提示词，也不插入对话历史：

- 原生 / 自定义框架：变量 `world_info`，由内置「本轮上下文」（`components/state/turn_context`）渲染为 `<world_info>` 块，与记忆、文档与事实召回并列。改写过本轮上下文或不使用该区块的框架，需要自行引用 `{{ world_info }}`。
- 酒馆框架：作为一条消息放在当前输入之前（深度 1，排在同深度的预设条目之后），按酒馆适配规则改为带 `【系统指令】` 标记的 user；「世界信息（前/后）」标记不自动映射世界书。

本轮上下文每轮都会重新生成且不写入历史，系统提示词与历史前缀保持逐字不变，因此世界书条目的增减不会破坏提示词缓存。

- 激活发生在提示词装配阶段（`PromptWorkspace.assemble`），覆盖主对话、据点群聊、社交运行时与提示词预览。据点执行与后台任务不注入世界书。
- 激活是纯函数：持续轮数通过向前多扫描对应轮次实现，不保存会话状态，因此重新生成、编辑或删除历史后结果自然一致。
- 触发概率：蓝灯由最近两条扫描消息决定，同一轮内多次装配结果一致；绿灯按触发它的那条消息（及其前一条）判定，同一次触发在扫描与粘滞期间结果一致，未通过的不会在粘滞期补上。
- 关键词只扫描对话正文：桌面与社交编译器通过 `worldbook_scan` 提供不含时间标记、平台账号与身份前缀、任务结果和图片档案的消息；其他装配退回历史与当前输入。
- 世界书页提供命中测试，可查看命中原因、被预算舍弃与未通过概率的条目，以及合并后的注入内容。

## 酒馆兼容

- 导入：酒馆独立世界书 JSON、角色卡 JSON 或其中的 `character_book`。转换蓝绿灯、关键词、顺序、启停、概率与粘滞。
- 酒馆的粘滞按消息数计算，导入时折算为对话轮数（向上取整），导出时乘 2。
- 插入位置统一为本轮动态上下文；原本不在“角色定义后”的条目在导入时统计提示。次关键词与逻辑、正则关键词（按普通文本匹配）、超出条目数或长度上限被截断的内容同样统计提示。递归激活、互斥组、冷却与延迟暂未实现。
- 导出为酒馆独立世界书格式，位置写为 @D1（系统角色，最接近本轮动态上下文），可直接导入酒馆；生效场景写入扩展字段 `infosChannels`，再次导入本应用时恢复。

## 存储

```text
@data/worldbooks/books/{id}.json   单本世界书（带修订号）
@data/worldbooks/settings.json     全局激活设置与全局启用的书
@data/worldbooks/bindings.json     角色绑定，以及已导入的角色内嵌世界书指纹
```

- 写入采用同目录临时文件再改名，目标文件被短暂占用时重试；损坏的单本世界书在加载时跳过并记录日志。
- 删除角色只移除其绑定，内嵌世界书的导入记录保留：同一角色重新出现（如内置角色）时重新绑定原来那本书，不重复导入。
- 保存携带修订号，与服务端不一致时拒绝（CONFLICT），避免覆盖其他窗口的修改。
- 全局启用列表按单本增删，保存激活设置时不提交列表；角色绑定保存时附带编辑前看到的绑定，服务端已被修改时拒绝（CONFLICT）并由页面载入最新绑定。
- 角色导出时，资源包中的 `worldbook.json` 以书库中当前绑定的主要世界书为准。加载角色目录时，若角色带有 `worldbook.json` 且尚未绑定主要世界书、该文件内容未导入过，则导入为新书（重名追加序号）并绑定；用户解绑后不会被同一份文件再次导入。

## API

| 操作               | API                                                                                                  |
| ------------------ | ---------------------------------------------------------------------------------------------------- |
| 书库列表与全局设置 | `GET /api/worldbooks`                                                                                |
| 新建 / 导入        | `POST /api/worldbooks`，`{name, entries?}`                                                           |
| 读取 / 保存        | `GET` / `PUT /api/worldbooks/:id`，保存传 `{name, entries, revision}`                                |
| 复制 / 删除        | `POST /api/worldbooks/:id/duplicate`，`DELETE /api/worldbooks/:id`                                   |
| 激活设置           | `PUT /api/worldbooks/settings`，`{scanDepth, tokenBudget}`                                           |
| 全局启用           | `POST` / `DELETE /api/worldbooks/settings/global-books/:id`                                          |
| 角色绑定           | `GET /api/worldbooks/bindings`，`GET` / `PUT /api/worldbooks/bindings/:agentId`，保存可带 `expected` |
| 命中测试           | `POST /api/worldbooks/test`，`{entries, text, channel}`，不保存                                      |
