# 快速上手

欢迎来到 PeroperoChat！跟着下面的步骤，和你的伙伴开始第一次聊天吧。

## 1. 打开应用

- **Steam 版或桌面版**：打开 PeroperoChat，在启动器中选择伙伴，点击「启动」。如果出现选择菜单，点击「应用模式」。
- **Docker 或开发版**：启动后打开应用主界面。

如果你已经进入主界面，就可以继续往下啦。

## 2. 配置 AI 模型

伙伴需要连接 AI 模型才能回复。开始前，请先准备好模型服务商提供的 **API 地址、API Key 和模型 ID**。部分服务可能不需要 API Key，以服务商说明为准。

1. 在左侧「设置」中打开「模型配置」，点击「服务商连接」。如果左侧只显示图标，可点击侧栏顶部的「固定展开」按钮。
2. 点击「新建」，在「品牌模板」中选择服务商，填写连接名称、API 地址和 API Key，然后点击「创建连接」。
3. 点击「关闭」，再点击「添加模型」，选择刚才创建的服务商连接。
4. 填写模型 ID，或点击「获取模型列表」后选择模型，再点击「添加」。
5. 在模型卡片上点击「测试」；测试成功后，点击「设为主模型」。如果卡片已显示「主模型」，就不需要再设置。

> 如果测试失败，请检查地址、API Key 和模型 ID 是否与服务商提供的一致。API Key 就像密码，请妥善保管，不要发给别人。

## 3. 告诉伙伴你是谁

打开左侧的「系统设定」，找到「用户人设」：

1. 在「你的名字」中填写你希望伙伴使用的名字。
2. 在「人设描述」中简单介绍你的称呼、兴趣或偏好。
3. 点击「保存」。

不想现在填写也没关系，以后随时可以修改。

## 4. 开始聊天

打开左侧的「对话」，选择一位伙伴，在输入框里打声招呼，点击发送就好啦！

想换伙伴或调整她的设定，可以打开左侧的「角色管理」。

## 5. 和桌宠互动

Steam 版和桌面客户端可以让伙伴出现在桌面上。打开应用后，在 Windows 任务栏右下角找到 PeroperoChat 图标，右键点击它，选择「桌宠召唤」。如果没看到图标，先点击任务栏的「^」展开隐藏图标。

也可以从启动器点击「启动」，在出现的菜单中选择「桌宠模式」。

桌宠出现后，可以试试这些操作：

- **互动和移动**：用鼠标左键点击伙伴，看看她的反应；按住并拖动，可以移动她的位置。
- **打开菜单**：点击伙伴身旁的光点，展开「对话」「语音」「互动」和「更多」菜单。点击「收起」可关闭菜单。
- **桌宠聊天**：在「对话」中输入消息并点击「发送」。点击「打开对话」可进入主界面查看完整回复和聊天记录。
- **语音聊天**：在「语音」中选择「按住说话」，按住「按住这里说话」，松开后发送。使用前需要在主界面的「语音功能」中配置语音识别。
- **更换造型**：在「互动 → 换个样子」中选择可用造型；部分造型还提供「动作小剧场」。
- **调整大小**：在「更多」中点击「滚轮调节」，滚动鼠标滚轮调整大小，再点击「结束调节」或按 Esc。
- **暂时隐藏**：在「更多」中点击「隐藏桌宠」；想再见到她时，在托盘右键选择「桌宠召唤」。

## 6. 使用任务栏托盘

Steam 版和桌面客户端运行时，任务栏右下角的托盘图标可以帮你快速回到应用：

- **单击图标**：打开或切回「工作台」。
- **右键图标**：选择「启动器」「桌宠召唤」或「工作台」。
- **完全退出**：右键图标，选择「彻底退出」。隐藏桌宠不会退出应用。
