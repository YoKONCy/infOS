# 主界面导览

应用主界面把对话、工作台和设置放在左侧导航中。本章按照界面上的分组介绍每个入口。第一次配置和聊天，可以先看[安装与上手](/guide/usage)。

## 打开主界面

Steam 版和桌面版可以在启动器中点击「启动」，在出现的菜单中选择「应用模式」；也可以右键任务栏托盘中的 PeroperoChat 图标，选择「工作台」。开发版和 Docker 版启动后，在浏览器中打开应用主界面。

Steam 版和 Electron 桌面客户端的主窗口顶部还有标签栏，可以打开网页和应用，详见[内置浏览器](/work/browser)。

左侧导航分为「交互」「工作台」「设置」和「高级」，通常进入主界面时首先看到「对话」。

- 在「对话」「工作区」和「据点」中，侧栏可能收起为图标；点击侧栏顶部的「固定展开」可显示名称。
- 点击「设置」或「高级」分组标题，可以展开或收起该组的入口。
- 窄屏界面点击左上角菜单按钮可以打开导航。

## 交互

### 对话

在「对话」中选择伙伴和历史会话，输入消息后发送。左侧会话栏可以「建立新会话」，也提供修改标题和删除会话的入口；对话顶部的「导出」可以导出当前会话历史。

输入栏提供会话模式和工具设置。模式会影响本次会话可使用的工具，详见[工具与权限](/work/tools)。

### 工作区

在「工作区」浏览当前伙伴的文件、打开或编辑支持的文件，并在协作栏与伙伴讨论。页面还提供文件搜索和工作终端。操作步骤见[对话与工作区](/companion/chat)，文件位置和恢复方式见[工作区与任务](/work/tasks)。

### 据点

在「据点」选择房间，与房间里的伙伴群聊；界面提供房间导航、成员区域和当前房间历史的「导出」入口。操作方法见[据点（群聊）模式](/companion/stronghold)。

## 工作台

### 总览

打开「总览」可以查看：

- **天气**：点击「设置城市」填写地点；已有地点后可「更换城市」，查看当前天气和三日预报。
- **Token 用量**：展开用量卡片查看统计、趋势和分类；上游未上报或部分上报时，页面会提示统计可能不完整。
- **旅途成就**：查看成就状态，点击刷新按钮重新读取。
- **统计入口**：「核心记忆」「近期对话」「任务中心」旁的箭头可打开相应页面。近期对话数字是最近最多 5 个会话的消息数之和；任务数字来自待触发提醒。
- **当前状态**：查看当前角色的「心情」「氛围」「想法」，也可以点击角色名称切换已启用的伙伴。
- **最近对话与系统健康**：查看近期会话摘要和服务端运行、存储信息。

总览还有全局「主动行为」：

| 选项 | 界面说明 |
| --- | --- |
| **关闭** | 暂停主动唤醒，已安排的定时任务继续运行。 |
| **智能陪伴** | 适时主动交流，未回应时减少打扰。 |
| **自主行动** | 主动搜索、整理信息并推进事项。 |

三种选项由所有已启用角色共用。展开「调度设置」可以修改间隔、每日回合上限和行动偏好，再点击「保存设置」；页面还显示下次唤醒、当日回合和「最近运行」。主动行为设置与会话工具模式分别管理。

### 对话日志

「对话日志」按会话展示记录。可以搜索对话摘要，按「角色」「来源」筛选，选择「最新在前」或「最早在前」，再展开会话查看消息。

普通会话提供「修改会话标题」和「删除整条会话」；消息旁可出现「复制」「删除该对话对」和「查看内部构造」等操作，具体取决于记录类型。删除时请留意界面给出的文件处理选项和确认信息。

「查看内部构造」提供「完整提示词」和「原始文本」视图，记录中有模型请求快照和 Token 信息时也会显示。历史记录能展示的内容取决于当时保存了哪些数据。

### 核心记忆

「核心记忆」提供「档案列表」和「关系图谱」两种视图，并可在「记忆」与「归档」之间切换。

- 搜索和筛选记忆；选择一条后查看详情、关联事件及可用的来源对话。
- 编辑记忆，或将记忆归档；在「归档」中可以恢复或永久删除。
- 使用「后台记忆」总开关控制后台整理，点击「按角色设置」可为每位伙伴分别开启或关闭；[记忆与知识](../companion/memory)中介绍了具体作用。点击「RAG 配置」调整相关检索设置。

归档、删除和召回的区别见[记忆与知识](/companion/memory)。

### 知识库

「知识库」分为「事实库」和「文档知识库」：

- **事实库**：搜索人物或事物，查看当前事实、历史事实和已撤回记录；选择事实后可进行编辑、撤回、还原或永久删除等操作。
- **文档知识库**：点击「导入资料」，选择「文本文件」「粘贴文本」或「网页」；选择资料后可以查看、更新、删除或在「检索」中查找内容。

资料整理和检索的详细说明见[记忆与知识](/companion/memory)。

### 任务中心

「任务中心」顶部的「派发新任务」可以选择执行角色、填写任务指令和完成条件，并选择完成后的交付方式。提交后可从任务卡片打开详情。

| 页面 | 可以做什么 |
| --- | --- |
| **进行中** | 查看后台任务、待触发提醒和需要关注的活动；任务卡片根据状态提供暂停、恢复或取消等操作。 |
| **历史记录** | 按标题或目标搜索，按完成、失败或取消筛选；打开记录查看结果，也可使用「一键已读」。 |
| **定时与提醒** | 展开「安排稍后的任务」，选择角色、时间、结果会话、重复安排并填写任务内容；还可以查看提醒和系统后台任务。 |

任务的状态、恢复和定时安排见[工作区与任务](/work/tasks)。

## 设置

### 角色管理

在角色图鉴中选择伙伴，按页面分区查看或修改：

- **身份档案**：头像、角色名称、对你的称呼、简介和对外公开档案。
- **人格内核**：核心人格和不同场景的表达方式。
- **交互反应**：桌宠点击、闲置和时段问候等台词。
- **能力协议**：按场景配置工具权限、专业技能和常驻能力说明。
- **运行来源**：查看角色来源和资源状态。

修改后点击「同步档案」保存；切换角色时若有未同步修改，界面会提示处理。页面还提供创建、导出角色包等入口，删除操作适用于用户档案。

### 系统设定

- **健全模式与预填充模式**：选择是否启用健全模式，或设置模型回复开头的预填充内容与方式。
- **动态填充深度**：在预填充下方选择「贴近本轮输入」或「前移到上轮输入」。调整的是最新状态与检索资料的位置，前移可能增加缓存开销。
- **用户人设**：设置用户头像，填写「你的名字」和「人设描述」，选择界面语言。
- **天气**：设置默认城市并预览天气。
- **完成提醒**：设置完成提示音；在支持的 Windows 环境下，还可以设置应用不在前台且桌宠隐藏时的完成通知。这些选项对当前设备生效。
- **外观设置**：选择主题、应用背景预设、动态效果和关键事件音效。背景预设 1、2、3 可以上传图片，并通过「细调背景」调整显示效果。
- **高级**：查看数据目录并选择日志级别。当前页面中的数据目录和字体大小控件为禁用状态。

名字和人设旁有「保存」按钮，页面底部也有「保存设置」；开关与部分选择项按界面提示即时保存。

### 桌面与家

在左侧「设置」中打开「桌面与家」。顶部可查看桌面操作、耳朵、陪看与感知状态，再按需要选择分区。

- **桌面操作** 控制总开关，设置停止快捷键。
- **感知与陪伴** 设置看屏幕、听声音、主动开口和陪看。
- **共享空间** 选择角色与会话，交换物品，管理记住的地点。
- **授权与记录** 查看授权、文件改动、活动记录和回收区。
- **保护设置** 调整程序保护、文件安全和记录保留。

前两个分区及程序保护在 Electron 桌面客户端中提供。浏览器可使用共享空间、授权记录和文件保护设置。

### 模型配置

「模型配置」页提供两个区域：「模型配置」和「向量模型」。

在「模型配置」中：

1. 点击「服务商连接」→「新建」，选择品牌模板，填写连接名称、API 地址和所需认证信息，点击「创建连接」。
2. 关闭连接窗口，点击「添加模型」，选择服务商连接，填写或获取模型 ID，完成后点击「添加」。
3. 在模型卡片点击「测试」，再按需要点击「设为主模型」。卡片还提供「回退」、编辑、删除，以及流式输出、图片输入等开关。
4. 点击「任务指派」可以选择系统任务使用的模型，或配置多模态转述；点击「角色指派」可以选择各伙伴的对话模型。

「向量模型」区域提供向量功能开关、Embedding 和 Reranker 配置；修改后使用「保存并激活」。这里的「索引维护」展示索引状态，并提供「重建」和「重建全部」。本地内置向量模型选项在界面中标记为待实现。

### 提示词

「提示词」页包含「框架」「槽位」「组件」「任务」「指派」「版本」六个分区。页面提供「新建框架」「导入预设」「导出预设」「校验」「保存草稿」和「发布」等操作；选中条目后可按其类型编辑、预览或指派。

框架如何组织、发布和生效，见[提示词框架](/advanced/prompts)。

### 语音功能

页面依次提供「桌宠语音与快捷键」「语音合成」和「语音识别 ASR」：

- **桌宠语音与快捷键**：选择输入方式、麦克风和按住说话绑定，设置快捷键以及口语答复、短句字幕。全局按住说话等功能受当前运行环境影响。
- **语音合成**：选择语音服务、添加声音预设、设置默认声音或当前角色的声音，使用「保存配置」保存，也可「保存并试听」。部分字段随服务类型显示。
- **语音识别 ASR**：开启后填写 API Base、API Key 和模型，可选择识别语言或获取模型列表。页面还显示唤醒词与灵敏度输入；当前实现尚未保存这两项修改。

### 工具与扩展

「工具与扩展」顶部依次提供「已安装」「资源版本」「插件」「扩展工具」「拓展功能」「MCP 服务」「技能」：

- 在「插件」中使用「导入 ZIP」，按提示审核后启用；插件卡片会根据状态显示停用、重载、卸载等操作。
- 在「MCP 服务」中添加和连接服务；在「技能」中导入技能文件夹或重新扫描。
- 「拓展功能」中的「管理来源」用于配置联网搜索和 PDF 解析的服务来源。
- 「已安装」汇总资源，「资源版本」管理受保护资源的版本，「扩展工具」管理官方扩展工具。

工具授权和扩展方式分别见[工具与权限](/work/tools)与[插件、技能与子应用](/work/extensions)。

### 分布式

「分布式」展示客户端接入设置和「当前服务器」，并提供服务器连接、同步和能力节点入口：

- 在「局域网与设备」或「服务访问与设备」中，可按环境设置访问入口、生成配对码并管理已配对设备。
- 在「添加服务器」填写地址和凭据，可以先「测试连接」，再「保存到我的服务器」。
- 「我的服务器」提供同步和删除操作；浏览器环境还会显示「设为当前服务器」。服务器管理与完整同步需要管理员凭据。
- 桌面客户端可通过「选择运行方式」在开屏中切换本地或远程模式，重启客户端后生效。
- 「能力节点」提供「生成一次性配对邀请」和节点、在线会话及可用能力的数量。

完整同步按页面确认后准备数据，重启服务后应用；界面也会在适用时提供「撤销上次同步」。操作步骤见[多设备与分布式](/deployment/distributed)。

### 数据与备份

在「数据与备份」的「导出与备份」区域，选择「配置」「角色」「内容」或「完整服务端」，按需要筛选具体内容，再选择「保存备份」或「导出到本机」。包含 API Key 和连接凭据时，需要设置至少八位的备份口令。

在「导入数据」中选择备份文件，按提示填写口令并预览。确认导入方案后，页面会提示重启服务端；重启时建立恢复点并应用导入。桌面本机、Docker 和远程服务的重启提示各有不同，请按当前页面操作。

### 社交配置

「社交配置」按 QQ、微信、Telegram、Discord 和「通用设置」分区。选择平台后，可以查看「连接与账号」、联系人和会话数据；QQ 还显示「状态卡片」和「收藏表情」。各平台的连接方式和可用功能以页面为准。

「通用设置」用于选择社交角色、调整社交模式和管理全局社交数据；具体平台的账号连接和主人身份在各平台页面设置。接入步骤和设置说明见[社交模式](/companion/social)。

## 高级

### 系统终端

「系统终端」显示实时系统日志，提供「自动滚动」开关和清空当前显示的按钮。工作区中的终端用于工作区操作。

### 危险区域

::: danger 这些操作无法撤销
执行前需要按提示输入确认短语。需要保留资料时，先到「数据与备份」导出。
:::

| 操作 | 页面说明的影响 |
| --- | --- |
| **清空对话记录** | 删除对话日志和消息历史，保留记忆节点与配置。 |
| **重置全部记忆** | 删除角色记忆、共享事实及关联日记，保留对话和知识文档。 |
| **恢复出厂设置** | 清除包括对话、记忆、配置和模型设置在内的数据。 |

实际执行范围和附加选项请以确认窗口为准。

存在尚未完成的清理任务时，页面还会显示「数据清理」状态；清理失败后可以点击「重试清理」。
