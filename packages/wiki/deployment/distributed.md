# 多设备与分布式

infOS 可以让多台设备连接同一台服务端：服务端管理角色、对话、记忆和工作区，客户端负责展示和交互，能力节点提供所在设备上的具体能力。它们可以在同一台电脑上，也可以分布在不同设备上。架构介绍见 [AIOS 架构](/advanced/aios)。

打开主界面左侧「设置」→「分布式」，可以管理设备、服务器连接与数据同步。本章分别介绍几种使用方式：

| 目的 | 使用方式 |
| --- | --- |
| 用手机或另一台电脑继续使用同一份数据 | 为新设备配对，连接当前服务端。 |
| 在桌面客户端使用远程服务 | 在启动页选择「连接服务器」。 |
| 从另一台服务端迁移数据 | 在当前服务端执行一次完整同步。 |
| 让其他设备提供工具能力 | 连接能力节点。 |

## 配对其他设备

用管理员身份打开「分布式」，找到「局域网与设备」或「服务访问与设备」。

1. 桌面本机服务在「局域网与设备」中开启「允许局域网访问」，确认「监听端口」，点击「应用设置」。开发版的独立入口也按页面开关和端口设置；Docker 使用部署时配置的访问入口。
2. 在「配对新设备」中选择或填写目标设备可以访问的「手机访问地址」或「设备访问地址」，点击「生成配对码」。地址填写 HTTP 或 HTTPS 的 IP 和端口，或服务域名；请使用目标设备能访问的地址。
3. 在新设备上扫码，或打开该地址后选择「设备配对」并填写配对码。填写「设备名称」，按需选择「保持登录 30 天」，点击「连接此设备」。

配对码有效期为五分钟，仅可使用一次；过期或已使用后，重新生成即可。配对成功后，新设备访问的是同一服务端的数据。管理员可以在「已配对设备」中查看设备和有效期，点击「撤销授权」；浏览器端也提供「退出此设备」。

连接失败时，请检查两台设备的网络、服务端地址和防火墙。Docker 环境请使用宿主机 IP 或部署域名；手机语音输入需要 HTTPS。具体部署见 [Docker 部署](/deployment/docker)。

## 桌面客户端连接远程服务

Steam 版和 Electron 桌面客户端可以连接已有的 infOS 服务端：

1. 首次启动时，在「选择运行方式」中选择「连接服务器」。已经进入应用时，可在「分布式」→「当前服务器」点击「选择运行方式」。
2. 填写「服务器地址」和「访问令牌」。需要单独指定能力通道时，展开「高级连接选项」填写「能力通道地址」；留空时使用服务器同域的 9121 端口。
3. 首次启动点击「验证并连接」；运行中修改配置时，按界面点击「保存并重启」。
4. 重启后在「当前服务器」核对名称、Server ID 和版本。

首次连接或证书发生变化时，如果出现证书确认窗口，请核对显示的证书信息。远程服务的业务入口和能力通道都需要从客户端所在设备可达；Docker 默认的能力端口绑定在宿主回环地址，远程接入需要按部署环境配置。

选择「本地运行」后，客户端使用这台电脑上的服务。切换运行方式改变的是客户端连接目标；业务数据随所选服务端保留。远程模式下，Steam 业务存档由远程服务端备份。

## 添加服务器与完整同步

服务器管理和完整同步需要**管理员凭据**。先在要接收数据的服务端打开「分布式」：

1. 在「添加服务器」填写来源服务器地址、「鉴权密码 / Token」和可选的显示名称。来源服务器需要提供管理员凭据。
2. 点击「测试连接」查看结果，再点击「保存到我的服务器」。
3. 在「我的服务器」找到来源，点击「从此服务器上同步最新数据」。
4. 阅读「同步全部数据」确认窗口并确认；等待页面提示数据准备完成。
5. 重启**当前接收数据的服务端**，让暂存的数据生效。

::: danger 完整同步会替换当前数据
同步方向是**所选来源服务器 → 当前服务器**。这是一次完整快照导入：应用时当前业务数据会被来源快照替换，系统会先保留当前数据的备份；当前机器的身份和设备连接凭据继续保留。
:::

两台服务端之后各自运行，新的变更需要再次手动同步。

同步会保存 NapCat 的账号配置和用户插件；程序文件由各设备自行安装，恢复时保留当前设备已安装的程序。

新版可以恢复旧快照；接收新版生成的快照时，接收端也需要更新。

同步完成后，「当前服务器」会在适用时显示「上次完整同步」和「撤销上次同步」。点击撤销后，还需要重启当前服务端，才能恢复同步前的备份。同步和撤销都请先核对当前服务器与来源，避免覆盖想保留的新数据。

浏览器访问时，「我的服务器」还提供「设为当前服务器」，用于切换页面连接；桌面客户端通过「选择运行方式」切换。切换连接和完整同步是两项独立操作。

## 连接能力节点

能力节点由所在设备主动连接服务端，提供它实际具备的能力。例如，Electron 客户端可以提供本机桌面和浏览器能力；独立 Node Host 当前提供节点本机的终端能力。能力能否使用，还取决于节点在线状态、工具授权与执行权限。

桌面客户端连接远程服务后会处理自身的能力通道连接。需要接入独立节点时：

1. 在服务端的「分布式」→「能力节点」点击「生成一次性配对邀请」。页面显示配对码、能力通道地址和失效时间。
2. 在运行 Node Host 的设备上，将服务端的能力通道地址提供给 `INFOS_HOME_SERVER`，将配对码提供给 `INFOS_PAIRING_CODE`，然后启动已准备好的 Node Host。按需使用 `INFOS_NODE_IDENTITY_PATH` 指定身份文件位置。
3. 返回「分布式」查看「已登记节点」「在线会话」和「可用 Offer」数量；这些数字概括连接与能力状态。

邀请有效期为五分钟，成功配对后节点保存设备凭据，后续重启可用保存的凭据连接。能力通道地址需要从节点可达；公网部署需配置可信的 WSS/TLS 入口。手机浏览器的设备配对用于访问应用；如需桌面、浏览器或远程终端等能力，需要相应的能力提供者在线。

## 遇到连接问题

- **页面提示需要管理员凭据**：使用管理员身份登录后管理服务器和完整同步；普通设备仍可按授权使用业务功能。
- **远程客户端连接失败**：核对服务器地址、访问令牌、网络和证书；需要本机能力时再检查能力通道地址和端口。
- **节点数量有变化，工具仍不可用**：检查在线会话与可用能力，并在角色和当前会话中检查工具授权。具体门禁见[工具与权限](/work/tools)。
- **同步已准备但数据还未变化**：重启接收数据的服务端，再检查「当前服务器」与同步状态。
