# 提示词框架

提示词帮助伙伴了解自己的身份、说话方式和当前任务。你可以使用内置框架，也可以调整框架或导入预设。

打开应用左侧的「设置 → 提示词」，就能进入提示词管理页面。如果侧栏只显示图标，可以先点击顶部的「固定展开」。

## 页面里有什么？

| 分类 | 用途 |
| --- | --- |
| **框架** | 安排对话中使用的提示词内容及顺序。 |
| **槽位** | 管理框架中可以引用的提示词模板。 |
| **组件** | 管理可以被其他模板引用的内容。 |
| **任务** | 管理日记、记忆整理等后台任务使用的提示词。 |
| **指派** | 选择不同角色或频道使用的框架，也可以替换模板。 |
| **版本** | 查看已发布的版本，并将旧版本恢复到草稿。 |

一般聊天可以先使用内置框架。想调整伙伴的性格或对你的称呼，也可以先去「角色管理」或「系统设定」修改，不一定需要改框架。

## 调整并使用框架

第一次修改时，可以先复制一份内置框架：

复制框架不会复制它引用的槽位和组件；直接修改这些共用模板，也会影响其他引用它们的框架。

1. 打开「框架」，在左侧选择要调整的框架，点击「复制」。
2. 在新建的副本中修改名称、内容或区块顺序。需要时可以开启或关闭区块。
3. 点击「渲染预览」，选择角色和频道后点击「刷新」，查看示例结果；也可以点击「校验」检查配置。
4. 点击「指派此框架」，选择角色和频道，再点击「应用到草稿」。
5. 确认无误后，点击页面顶部的「发布」。新配置从下一轮生效。

> 「保存草稿」只保存编辑内容，不会让它立即用于对话。点击「发布」时会先保存并校验；如果有错误，需要修复后才能发布。

预览会读取所选角色的人设，但记忆和聊天历史使用示例内容，不能代表真实对话中发送给模型的全部内容。

### 指派范围

在「指派」页，可以为所有角色、某个角色或不同频道选择框架。范围按**全局 → 频道 → 角色 → 角色频道**逐级覆盖，越具体的已有指派优先。例如，为某个角色单独指定的框架，可能覆盖你设置的全局框架。

新建或导入框架时，也可以选择「全部对话」「指定范围」或「稍后指派」。选择「全部对话」会替换已有角色和频道的框架指派；发布后才会生效。

## 新建框架

点击页面顶部的「＋ 新建框架」，选择格式、填写名称和生效范围，再点击「创建框架」：

- **infOS 原生格式**：从内置框架开始，可以继续调整槽位和组件。
- **SillyTavern 格式**：适合使用酒馆风格的提示词和宏。
- **自定义框架**：从空白开始，可以填写完整正文，或自行编排区块。

SillyTavern 格式和自定义框架可以选择是否「保留对话历史」。空白框架需要自己编写所需的人设和规则。创建后记得预览、校验并发布。

## 导入和导出预设

点击顶部「导入预设」，选择 JSON 文件。导入框架预设或酒馆预设时，可以查看提示、选择生效范围，再点击「导入草稿」。检查并发布后才会生效。

导入完整工作区备份会提示替换当前草稿；这与导入单个框架预设不同。建议先用「导出预设」保存需要保留的内容。

「导出预设」提供两种选择：

- **框架预设**：导出所选框架及其引用的模板，适合分享或迁移。
- **完整工作区备份**：导出全部框架、模板和指派。

酒馆预设支持 Chat Completion 格式，暂不支持 Text Completion 指令模板。导入不会更改模型配置，也不会执行酒馆扩展脚本；请留意导入时显示的提示。

## 恢复以前的版本

打开「版本」，选择一个已发布版本，可以查看它与当前草稿的差异。点击「恢复到草稿」并确认后，检查内容，再点击「发布」才能让恢复的版本生效。

如果只想把某个内置条目恢复原样，选中它后点击「恢复内置」；顶部的「内置预设」则会用整套内置配置替换当前草稿。这些操作都需要发布后才会影响后续对话。
