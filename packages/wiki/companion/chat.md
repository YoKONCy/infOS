# 对话与工作区

「对话」适合与伙伴交流和提出任务；「工作区」把文件、终端和协作对话放在一起，方便围绕文件工作。两处可以使用同一位伙伴的同一个会话。

开始前，请先按[安装与上手](/guide/usage)配置 AI 模型和用户人设。

## 开始一段对话

1. 在主界面左侧点击「对话」。
2. 在对话页左侧的「伙伴」列表中选择一位角色。列表收起时，点击边缘箭头展开。
3. 在下方输入框填写消息，点击发送按钮。

电脑上按 Enter 发送，Shift + Enter 换行。窄屏界面可以点击发送按钮；输入法正在组字时，Enter 用于完成输入。

### 切换伙伴和会话

「伙伴」下方是当前角色的「历史会话」。每位伙伴都有一条带「主会话」标记的主线，首次进入时会打开它。点击底部「建立新会话」可以新建侧线，单独聊一个话题或处理任务。切换后，当前窗口会记住你的选择。

主会话会逐条显示伙伴正式发出的消息，伙伴也可以连续说话、追问。你可以一次回答多个问题，或补充新的内容。点击「查看执行过程」可以展开思考和工具记录。主会话中的「生活经历」可以展开查看伙伴在据点亲历的近期消息。

主会话旁的「清空重置」会清理聊天、心流、计划和会话变量，保留伙伴的长记忆、共享状态、文件及会话设置。侧线提供「删除整条会话」，各会话都可以改名和导出。

回复或切换正在进行时，界面会暂时限制部分切换操作，请留意页面提示。

### 从某一轮继续新话题

在侧线中，将鼠标移到伙伴的回复上，点击「从此处新建会话」。系统会复制截至这一轮的完整对话，包含附件、思考和工具记录，并打开新侧线。原会话完整保留，两边可以分别继续聊天。主会话通过「清空重置」维护历史。

新侧线继承当前的模型、工具、Skills、心流、计划和会话变量。伙伴的心情、心声、持续目标等状态与长记忆、工作区由同一角色共享。

### 编辑和撤回

将鼠标移到消息上，可以看到复制、编辑和删除等操作。点击编辑按钮后，可以选择「仅保存」，或「保存并重新生成」。

侧线删除对话对或选择重新生成时，系统会从对应轮次处理后续对话，并检查相关工作区文件。出现确认窗口时，请先查看将恢复或保留的文件，再决定是否继续。删除整条会话时，界面说明为删除会话记录、保留文件。

主会话支持逐条编辑和撤回。选择重新生成时，会处理对应输入和相关回复，保留其他消息。已形成的长记忆会保留，记忆来源页会注明来源的撤回或修订情况。

文件恢复的适用范围见[工作区与任务](/work/tasks#工作区文件如何恢复)。

### 导出会话

点击对话顶部「导出」，按需要选择是否包含思考内容和工具调用参数与结果，再点击「导出 Markdown」。文件保存到当前客户端。

## 输入栏

对话页和工作区协作栏使用相同的输入组件，主要入口位于输入框下方：

| 入口 | 用途 |
| --- | --- |
| **模型** | 为当前会话选择模型；可选项来自已配置的模型。 |
| **思考强度** | 选择当前模型支持的档位，或选择「跟随模型」。 |
| **会话模式** | 在「极简」「聊天」「工作」之间切换。 |
| **输入** | 选择识图方式或语音输入方式。 |
| **会话工具** | 查看本会话的工具开关和「执行权限」。 |
| **Skills** | 选择本会话要使用的技能。 |
| **/ CMD** | 打开命令面板，可搜索新会话、清空输入、停止生成或切换角色。 |
| **添加文件** | 点击加号选择附件。 |

模型、模式、工具和 Skills 设置按当前会话管理。伙伴执行期间，部分设置会暂时锁定。

### 模式与执行权限

点击输入栏显示的模式名称，选择「极简」「聊天」或「工作」。不同模式开放的工具范围不同；需要伙伴处理文件或使用终端时，可以选择「工作」并检查工具权限。

点击「会话工具」可搜索、启用或禁用本会话的工具，并在「手动审批」「自动执行」「自动审批」「完整权限」之间选择「执行权限」。各档位的区别见[选择执行权限](/work/tools#选择执行权限)。

工具还受角色授权、当前模式及运行环境约束。页面会标出「系统必需」或「模式未开放」的项目。具体规则见[工具与权限](/work/tools#权限门禁如何工作)。

### 选择 Skills

点击「Skills」勾选要使用的技能，修改后自动保存。新会话默认关闭，启用后伙伴直接获得完整指引；取消勾选后，后续对话不再加入这项指引。极简模式会暂停使用 Skills，切回聊天或工作模式后沿用原来的选择。

### 发送图片和文件

点击输入栏的加号选择文件，也可以将文件拖入对话区域，或在输入框粘贴剪贴板中的文件。每轮最多添加 5 个附件，单个文件上传上限为 100 MB；添加后可以查看上传状态、取消附件，部分失败项提供重试。

图片理解取决于当前模型的图片输入能力或已配置的多模态转述。在「输入」中可以选择「自动选择」「原生多模态」或「多模态转述」，可用选项以界面显示为准。

PDF 解析需要配置相应来源。较大文件或当前无法直接处理的附件可能只保存原件供后续读取；发送前可以留意附件卡片上的状态。

### 语音输入

点击「输入」，选择下面的方式后开始录音；说完点击「停止」：

- **语音转写**：录音转成文字，确认或编辑后发送。使用前请在「语音功能」配置语音识别。
- **原生音频**：录制原音，试听后发送。需要使用 Gemini 协议并在模型卡片开启音频输入。

输入栏的麦克风按钮也可开始或停止录音；麦克风需要系统授权，浏览器访问时还受连接环境限制。

### 回复期间继续输入

伙伴正在回复时，可以继续输入并选择「加入队列」。展开「消息队列」后，可暂停或继续发送、调整顺序、退回输入栏编辑，或删除待发送的消息。队列中的「立即提交」会等待当前工具操作完成后进行交接。

## 使用工作区

在主界面左侧点击「工作区」。页面顶部显示当前伙伴和文件；左侧是资源栏，中间是文件区和终端，右侧是协作栏。顶部按钮可以展开或收起资源栏、终端和协作栏。

每位伙伴有自己的工作区；同一伙伴的多个会话可以使用同一工作区中的文件。文件保存在服务端所在设备上：连接远程服务或使用 Docker 时，请以服务端及其数据挂载为准。

### 浏览、搜索和管理文件

- 点击资源栏的「文件」，展开文件夹并选择文件，在中间打开。
- 点击「搜索」，输入关键词并执行搜索，再点击结果打开文件。
- 点击「刷新资源」更新列表；右键文件或文件夹可以选择「重命名」或「删除」。删除文件夹会一并删除其中的内容。
- 桌面客户端连接本机服务时，可点击「在系统文件管理器中打开工作区」。

### 查看和编辑文件

文件会在中间区域以标签页打开。支持编辑的文本可以直接修改，点击「保存」或按 Ctrl + S 保存；标签上的圆点表示尚未保存。关闭未保存文件或离开工作区时，界面会提示处理修改。

Markdown 文件可切换「编辑」与「浏览」；图片、PDF 等支持的文件可在页面预览。「全屏浏览」可以放大当前文件视图。过大的文本或部分搜索结果以只读方式打开；如果保存时文件已被外部修改，页面会提示处理。

### 引用文件内容

1. 在工作区打开文本文件；如果是 Markdown，选择「编辑」视图。
2. 选中想讨论的文字，点击「引用选区」。
3. 在右侧协作栏输入要求并发送。

选区最多 4000 字。输入框上方会显示本轮附带的文件、选区或当前终端；点击对应项目旁的关闭按钮，可以从本轮材料中移除。完成发送后，选区会清除。

### 工作终端

展开工作区底部「终端」面板，可以查看当前终端，也可以点击「新建终端」。终端提供「历史」、固定、Ctrl+C、停止和归档等操作；顶部按钮还可以收起或最大化终端。

终端运行在服务端所在环境。执行命令前，请确认当前连接的服务和命令内容。

### 与伙伴协作

右侧协作栏可以直接发送消息、查看回复，并处理伙伴提出的问题或审批请求。点击顶部「与……协作」区域可打开「切换会话」，选择已有会话，或点击角色旁的加号新建会话；「导出」用于导出当前工作区会话历史。

工作区打开的文件和当前终端会显示在协作栏的「当前上下文」中。伙伴需要读取或修改文件时，还会受会话模式、工具权限及执行策略约束。
