# 记忆与知识

伙伴可以把值得保留的经历整理成长期记忆，也可以查阅共享事实和你导入的资料。对话时，系统会根据当前话题、设置和权限，挑选可能有帮助的内容提供给模型。

## 记忆和知识分别保存什么？

| 内容 | 用途 | 范围 |
| --- | --- | --- |
| **对话历史** | 保存会话中发生过的消息，供当前或后续对话参考。 | 按会话保存。 |
| **事件记忆** | 记录伙伴经历过、值得长期保留的事情。 | 与角色关联，可以跨会话使用。 |
| **事实库** | 按人物或事物整理事实、别名和变化记录。 | 供获授权的角色共享，主会话按权限修改。 |
| **日记** | 回顾当天经历。 | 与角色关联，保存在工作区。 |
| **记事本** | 主动记录简短要点和提醒。 | 同一角色的主、侧会话及据点按权限共享。 |
| **文档知识库** | 保存你导入的文本与网页资料，供检索和查阅。 | 供获授权的角色共享。 |

例如，一次旅行的经历可以成为伙伴的事件记忆；某人的称呼或偏好可以整理成事实；旅行攻略可以作为文档资料导入。它们各自保存，也有各自的检索设置。

## 事件记忆如何形成？

一条事件记忆记录一件经历的叙述，还可以包含事件时间、重要度、情绪、人物、地点、物品和主题，以及来源对话和事件之间的关系。具体字段随记录内容而变化。

开启「后台记忆」后，系统会整理主会话和尚未覆盖的据点亲历，提炼有长期价值的事件，并维护它们的关系。伙伴可以主动查询这些事件。

侧线适合单独聊天和处理任务，历史由该会话保存。需要长期记住的事，可以直接告诉伙伴请它记下来。已有事件的关联、反思和日记继续按角色统一维护。

后台补记按角色累计在线时间安排：达到约八小时后开始处理符合条件的对话。实际结果取决于可用的对话、角色和模型状态，也可能需要等待重试。

在「核心记忆」页，「后台记忆」是总开关；点击旁边的「按角色设置」，可以分别决定每位伙伴是否进行后台整理，修改后自动保存。例如，可以关闭 Pero，让其他伙伴继续整理。各角色默认开启，总开关关闭时所有角色暂停，角色选择会保留。关闭后，已有记忆和整理进度会保留，记事本维护、主动查询和对话自动召回分别受工具权限及其设置管理。

## 让伙伴记下特别要点

每位伙伴都有自己的记事本，主文件在工作区的 `notes/MEMORY.md`，其他 Markdown 附页放在同一目录。你可以直接说“把这个习惯记下来”，或请它“整理一下记事本”。主会话和侧线共享这份文件，据点中的伙伴也可以按权限使用。

主文件会作为对话资料读取，附页按需查阅。想调整内容时，可以直接让伙伴修改文件。适合所有伙伴共享的客观信息可以记录到事实库，这类修改由主会话执行。

一项工作结束后，可以让伙伴清理工作上下文。它会先记录必要要点，再调用清理工具，后续交流从新的工作阶段继续。聊天原文和执行记录可从各自入口查阅。

## 伙伴怎样想起一件事？

主应用对话可以根据当前话题**自动召回**相关事件；伙伴也可以在工具可用时主动查询。自动召回会从当前角色的有效事件中检索，并补充时间轴末尾的事件和命中事件的直接前一个事件，帮助模型了解前后文。

基础检索结合文字和可用的语义向量。启用高级检索后，系统可以利用已有的事件关系扩展线索；高级检索依赖可用的向量功能，相关选项会影响自动召回。检索结果仍会经过上下文编译和长度预算的选择。

事件记忆的自动召回与文档、事实的自动召回分别设置。社交应用也有自己的记忆处理与配置。上下文如何组织这些内容，请看[上下文编译](/advanced/context)。

### 调整事件记忆召回

1. 打开左侧「核心记忆」，点击「RAG 配置」。
2. 选择「桌面对话」或「据点群聊」，调整「自动召回」「最近对话轮数」和「召回事件数」。
3. 如需调整关联检索，进入「高级检索」；完成后点击「保存配置」。

桌面对话与轻量陪伴共用桌面设置，据点群聊使用自己的场景设置；高级检索参数由这两个场景共用。页面上的配置由所有角色共用。关闭某场景的自动召回后，已保存的记忆仍然保留，伙伴也可以在工具开放时主动查询。

默认配置为桌面对话与据点群聊开启事件记忆自动召回，高级检索关闭。已有配置会沿用你保存的设置。

## 查看和管理记忆

打开左侧「核心记忆」，可以在「档案列表」和「关系图谱」之间切换。列表支持按角色、来源、时间、重要度和关联内容等条件筛选；选择事件后，可以查看详情、时间轴和已记录的关系。来源对话仍可用时，也可以展开查看原始对话。撤回消息或清空主会话后，已经形成的记忆会保留，来源页会标示相应变化。

你可以编辑记忆，也可以将它归档。归档后的事件保留在「归档」中，退出通常的对话记忆检索；需要时可以恢复。

::: danger 永久删除无法恢复
「永久删除」会删除选中的记忆及关联日记。暂时退出召回时，选择「归档」。
:::

### 伙伴的日记

「后台记忆」总开关和对应角色的开关都开启时，系统会在服务端本地时间约 21:00 尝试整理当天资料，为启用的角色生成日记。生成需要可用模型和相关运行条件；完成的 Markdown 文件保存在角色工作区的 `dailynotes` 文件夹中，内容较多时可能分成多个文件。

日记记录的是生成时可用的资料；后台补记和日记有各自的执行进度。你可以在「工作区」中打开这些文件。

## 事实库

事实库围绕人物或事物建立对象，记录名称、别名和事实。例如，可以为同一个人保存多个称呼，以及一条带来源和时间的偏好记录。伙伴在工具开放时可以查询、记录和更新事实。

打开左侧「知识库」，选择「事实库」，可以搜索对象、别名或事实内容。选择一个对象后，可以查看当前事实、历史事实和已撤回的事实：

- 点击「编辑事实」可以修正当前内容，系统保留旧版本。
- 点击「撤回」可以让事实退出有效集合，同时保留记录；符合条件的已撤回事实可以「还原」。
- 点击「永久删除」可以删除相应事实。

在事实库页面开启「事实自动召回」后，系统会按本轮话题查找少量相关的有效事实。此开关默认关闭；自动召回还需要当前会话开放查询事实的工具，并有可检索内容。

## 文档知识库

文档知识库适合保存需要反复查阅的资料，例如说明、笔记或文章。导入后，系统使用整理模型生成摘要和关键词，并按内容组织成可检索的部分；原文也会保存在知识库中，供查看和展开。

### 导入和检索资料

1. 打开左侧「知识库」，选择「文档知识库」，点击「导入资料」。
2. 选择「文本文件」「粘贴文本」或「网页」，填写内容后点击「导入」。
3. 等待资料显示「可检索」，再选择资料查看摘要、关键词和原文，或在「检索」中查找。

文本文件支持 TXT、Markdown、JSON、CSV 等 UTF-8 文本，单个文件最多 8 MiB；资料内容上限为 400K Token。网页导入读取可获取的正文，登录后或由脚本加载的内容需要另行提供。

资料有「待整理」「整理中」「可检索」和「整理失败」等状态。整理失败时可以查看原因并点击「重试」；更新资料后，系统会重新整理，整理期间该资料暂时退出检索。删除资料会删除知识库中的资料和检索数据，原始文件保留。

文档检索可以使用关键词、语义或正则等方式；实际可用的方式取决于索引和向量模型状态。向量暂时不可用时，页面可能显示「仅文本检索」或相应索引状态。检索结果提供摘要、来源和命中片段，可按需展开原文。

在文档知识库页面开启「文档知识自动召回」后，系统会按当前话题选择少量相关资料摘要。这项开关默认关闭；自动召回需要当前会话开放检索知识工具，并有整理完成的资料。伙伴也可以在工具开放时主动检索。

## 模型与索引

在「模型配置」的「任务指派」中，可以分别为「整理长期记忆」「整理记忆关系」和「知识整理」选择模型；未单独指派时使用主模型。知识导入需要可用的知识整理模型或主模型。

「模型配置」中的「向量模型」用于语义检索。文字检索也有自己的索引；文档页面提供「重建索引」入口。模型、索引或后台任务出现异常时，可以先查看对应页面的状态，再检查模型连接和配置。

使用远程模型或向量服务时，相应功能会将需要处理的对话、文档内容或检索文字发送给所配置的服务。选择服务和导入资料时，可以根据内容的敏感程度安排。

## 常见问题

**伙伴为什么暂时没有想起一件事？**

可以先到「核心记忆」搜索对应角色的事件，确认内容与归档状态，再检查当前场景的自动召回设置。召回还会受到检索结果和上下文预算影响；你也可以在对话中补充背景。

<CompanionNote who="pero">

要是 Pero 一时没想起来，直接提醒一句「上次我们聊过……」就好！把背景说清楚，比等我慢慢翻小本本快多啦。

</CompanionNote>

**开启自动召回后，资料会全部发给模型吗？**

系统根据本轮话题选择相关内容：事件记忆按场景设置召回，文档自动召回提供少量摘要，事实自动召回提供少量有效事实。伙伴还可以按需使用已开放的查询工具。

**记忆与知识会自动同步到其他服务端吗？**

记忆、事实和知识库保存在当前服务端的数据中。更换服务端或迁移部署时，请结合备份与恢复功能处理数据。
