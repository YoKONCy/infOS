# 社交模式

社交模式让伙伴通过已连接的社交账号与你和其他人交流。它连接外部平台；应用内部与多位伙伴聊天的功能见[据点（群聊）模式](/peripheral-systems/stronghold)。

## 开始之前

1. 按[快速上手](/guide/usage)配置 AI 模型和用户人设。
2. 在主界面左侧打开「设置」→「社交配置」。
3. 选择「通用设置」→「社交身份」，选好负责社交回复的伙伴，点击「切换角色」。
4. 选择要使用的平台，按照下方步骤连接账号，并在该平台的「主人身份」中确认你的身份。

当前由通用设置中选定的一位角色负责社交回复。她使用自己的角色设定和指派模型；可以在「设置」→「模型配置」→「角色指派」中调整模型。

平台标签会显示「未启用」「未连接」或「已连接」等状态。连接完成后，前往对应的社交应用发消息试试；回复还受平台权限、消息设置和模型状态影响。

## 连接 QQ

QQ 通过 NapCat 连接，支持私聊和群聊。在「社交配置」中选择「QQ」→「连接与账号」，首次使用时点击「启用 QQ」。

### Steam 版与 Electron 桌面客户端

1. 在「进程管理」中点击「一键安装」，安装完成后点击「启动」。
2. 点击「打开管理页」，在打开的页面中完成 QQ 登录和验证。
3. 返回社交配置，查看「Bot 连接」是否显示「已连接」。
4. 在「主人身份」中填写「主人 QQ 号」，点击「保存」。

本机 NapCat 的连接会自动配置。页面也提供「停止」、版本更新和「运行日志与排障」；更新前按界面提示停止 NapCat。使用远程服务时，请核对 NapCat 和服务端的连接状态。

### 浏览器访问与 Docker

页面在非 Electron 环境显示外部连接说明。请独立运行 NapCat，按照页面显示的「WS 端点」，将 OneBot v11 反向 WebSocket 连接到 infOS 服务端；页面中的 `<host>` 要换成 NapCat 能访问到的服务端地址。连接后查看页面状态，并填写「主人 QQ 号」。

## 连接微信

微信通过 ClawBot / iLink 连接，目前支持私聊。

1. 选择「微信」→「连接与账号」，首次使用点击「启用微信」。
2. 点击「获取登录二维码」，用微信扫一扫，并在手机上确认。
3. 按页面提示完成登录；如果要求验证码，在页面填写微信显示的验证码并提交。
4. 在「已连接账号」确认连接状态，然后通过微信私聊与伙伴交流。

二维码过期时可以重新获取。页面默认识别扫码账号为主人；需要覆盖时，可在「微信主人标识」填写 iLink 返回的用户标识并保存。

## 连接 Telegram

1. 在 Telegram 中向 `@BotFather` 发送 `/newbot`，按提示创建机器人并取得 Token。
2. 在「社交配置」选择「Telegram」→「连接与账号」，首次使用点击「启用 Telegram」。
3. 填写「Telegram Bot Token」，点击「添加或更新 Bot」。在「主人身份」填写你的数字 **Telegram User ID** 并保存。
4. 私聊时先向机器人发送 `/start`；群聊时将机器人加入群组。

Telegram 支持私聊、群组和论坛话题，话题中的回复会保留在原话题。群消息的读取范围取决于平台权限：关闭 Group Privacy 或授予机器人群管理员权限后，可在添加或更新 Bot 时开启「群聊主动观察」。这项开关关闭时，页面说明仍可处理私聊与群内提及。同一个 Token 只能由一个服务接收更新，切换服务前请先停止其他接收端。

## 连接 Discord

1. 在 Discord Developer Portal 创建应用并添加 Bot，通过 OAuth2 的 `bot` scope 将机器人邀请到服务器。
2. 为机器人授予查看频道、读取历史、发送消息和附件等所需权限；使用线程时还需要相应线程权限。
3. 在「社交配置」选择「Discord」→「连接与账号」，首次使用点击「启用 Discord」。
4. 填写「Discord Bot Token」，点击「添加或更新 Bot」。在「主人身份」填写你的数字 **Discord User ID** 并保存。

如需让伙伴主动观察频道，在 Developer Portal 的 Bot 设置中开启 Message Content Intent，并在添加或更新 Bot 时开启页面上的同名选项；服务器和频道权限仍需分别配置。修改权限或凭据后，重新提交该 Bot 的 Token。Discord 支持私聊、文字频道和线程。

微信、Telegram 和 Discord 的「已连接账号」区域提供「重新连接」和「移除」；移除时按界面确认。

## 伙伴何时会回复

收到私聊或群聊消息后，社交应用会结合会话内容、角色设定和相关配置处理。群里有人提及伙伴时会触发处理；开启群聊主动观察后，伙伴也可以在合适的时候参与讨论。她会根据上下文决定回复、等待或暂时略过，实际结果以平台中的消息和页面状态为准。

在「通用设置」→「社交模式」中可以调整：

| 设置 | 作用 |
| --- | --- |
| **任务与恢复** | 设置整轮、模型请求的时间上限和自动重试次数。 |
| **夜间静音** | 设置安静时段，期间暂停主动审视群聊。 |
| **群聊主动策略** | 开关主动参与，并设置每群的最少审视消息数和观察间隔；单个群的配置优先于默认策略。 |
| **名单策略** | 设置陌生人私聊、群白名单、群黑名单和用户黑名单。陌生人私聊选择「忽略」时，仅主人私聊进入处理链。 |
| **群聊参与节奏** | 查看各群的参与状态和冷却；可在适用时点击「恢复正常观察」。 |
| **连续互聊保护** | 设置与机器人互聊及单位时间内的处理、模型请求和发送上限，查看模型添加的机器人标记。 |

名单输入框提示使用「平台:会话标识」或「平台:账号」，按页面示例填写。修改后点击「保存社交模式」。如果出现「社交回合」，可以展开查看处理状态、调用记录和可用的后续操作。

各群分别计算观察时间和冷却。连续几次选择略过后，伙伴会逐步延长冷却；进入低活跃后，新 @ 可以唤醒，也可以在「群聊参与节奏」中手动恢复。平台是否向机器人提供群消息，同样会影响主动观察。

## QQ 状态卡片与收藏表情

QQ 页面另有两个分区：

- **状态卡片**：设置标题、主题、布局、配色和展示项目，点击「实时预览」或「保存」。卡片用于在 QQ 主人私聊中查看设备状态。
- **收藏表情**：查看平台账号的收藏，点击「同步」更新列表；也可以编辑并保存描述，或按提示移除收藏。同步结果以页面显示为准。

## 联系人与数据

各平台的「联系人」展示当前社交角色保存的联系人印象，选择联系人可查看身份信息、印象及来源，也可以「清除印象」。这里展示的是已保存的印象。

各平台的「会话数据」可以指定账号、私聊或群聊及目标标识，清理对应的会话记录。微信页面提供私聊选项。

在「通用设置」→「全局数据维护」中，可以管理当前社交角色的全部聊天记录、社交长记忆或全部社交数据，也可以查看索引和数据清理状态。不同操作的删除范围在页面列出；全局清理需要按提示输入当前角色名确认。

社交应用有自己的消息和记忆处理流程。「设置」→「模型配置」→「任务指派」中的「整理社交记忆」用于选择整理社交互动时使用的模型；图片理解取决于平台提供的内容及模型的视觉能力。更多背景见[记忆与知识](/core-systems/memory)。
