# 内置浏览器

内置浏览器让你在桌面客户端里打开网页，也能让伙伴在获得所需权限后查看和操作网页。聊天时可以通过「浏览器旁观」小窗查看伙伴正在处理的页面。

## 自己打开网页

Steam 版和 Electron 桌面客户端的主窗口顶部有标签栏：

1. 点击标签栏的 **+**，或按 Ctrl + T，新建标签页。
2. 在「输入网址或搜索内容」中填写网址或关键词，按 Enter 或点击右侧箭头。
3. 打开后，使用顶部地址栏访问其他页面；左侧按钮可以后退、前进、刷新或停止加载。

输入关键词时会使用 Bing 搜索。点击顶部标签可以在网页和 infOS 主界面之间切换；点击标签上的关闭按钮可以关闭网页。也可以用 Ctrl + Tab 切换标签、Ctrl + W 关闭当前标签。

网页入口支持 HTTP 和 HTTPS。网页无法加载时，页面会显示错误和「重新加载」按钮。

开发版、Docker 等通过浏览器访问的主界面没有桌面标签栏；伙伴能否使用内置浏览器，取决于是否有已连接且可用的浏览器能力提供者。

## 请伙伴使用浏览器

在「对话」中选择伙伴，将会话模式切换为「工作」，然后直接说明目标，例如「打开这个网页，帮我整理主要内容」或「预览工作区里的 HTML 页面」。伙伴可以根据任务搜索、打开和读取网页，操作页面控件，或在条件满足时查看网页截图。

浏览器操作属于按需展开的高级工具，伙伴会在需要时获取可用工具。实际操作还受角色授权、会话工具开关、执行权限和浏览器能力连接影响。你可以在输入栏的「会话工具」中检查开关和执行权限；需要确认时，按对话中的审批提示处理。详细说明见[工具与能力](/core-systems/tools)。

网页截图和图片的理解还取决于模型的视觉能力。工作区 HTML 通过授权预览入口打开；可以让伙伴查看渲染效果并继续修改文件。

## 查看伙伴正在做什么

当当前对话或相关任务产生可旁观的浏览器会话时，对话页面可能显示「查看浏览器」按钮或「浏览器旁观」小窗；后台任务也可在「任务中心」的任务详情中查看。

- 点击「查看浏览器」展开小窗，点击小窗右上角的 **×** 收起。
- 拖动标题栏移动小窗，使用 **−**、**+** 或拖动边缘调整大小。
- 有多个可观看的会话时，通过小窗中的「选择浏览器会话」切换。

小窗展示只读画面和页面标题。等待画面、页面关闭或连接中断时，小窗会显示相应状态。收起小窗只改变观看界面，伙伴的任务会继续按其状态运行。

在桌面客户端中，伙伴打开的页面也会出现在顶部标签栏。伙伴操作该页面时，标签和地址栏会显示「Agent 操作中」，页面暂时锁定；等操作结束后可以切换到该标签查看或操作。

## 页面与登录状态

自己新建的网页和伙伴打开的网页使用不同的浏览器空间，登录状态分别保存。伙伴的活动页面按对话或任务区分；页面仍然存在时，可以回到对应会话继续交给伙伴处理。

内置浏览器最多同时打开 8 个网页标签。伙伴创建且未被手动保留的页面在浏览器空闲一段时间后可能自动关闭；自己打开或点击查看过的页面会避开这项空闲回收。

当前网页权限请求会被拒绝，默认下载也处于关闭状态；下载等操作受浏览器能力和执行权限约束。遇到登录验证、设备权限或下载受限时，请留意页面与伙伴的提示。
